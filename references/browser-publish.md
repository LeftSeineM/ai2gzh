# 微信网页后台发表流程

适用于个人订阅号，以及选择通过网页后台操作的其他账号。下面记录了实际跑通的页面行为，是定位参考，不是永远不变的选择器。

## 登录和编辑

使用用户拥有的公众号登录会话。独立自动化配置目录应保存在用户指定的数据盘，并留在本机。管理员扫码由用户完成；登录成功不意味着以后每次发表都无需验证。

从公众号首页“新的创作”进入“文章”。它可能打开新标签页，必须切换到实际编辑页，不在旧首页继续查找编辑控件。

本次观察到的控件：

| 用途 | 页面线索 |
| --- | --- |
| 标题 | `请在这里输入标题`；也可能是 `.ProseMirror` 富文本区 |
| 作者 | `请输入作者` |
| 正文 | `.ProseMirror` 富文本区；与标题编辑器区分 |
| 封面入口 | `拖拽或选择封面` |
| 保存 | `保存为草稿` |
| 发文 | `发表` |

先观察当前 DOM、可访问性树或截图，确认当前布局再操作。页面往往同时包含隐藏弹窗中的同名按钮，限定可见控件和对应对话框。不要盲目点击第一个匹配项。

HTML 可通过支持 HTML 的剪贴板粘贴进正文。重试填入正文时先选中正文已有内容再替换，避免把同一文章追加两遍；不要在整个页面上误用全选。

若新功能教育弹窗遮挡编辑器，读取该提示，关闭确属说明性质的“我知道了”。不使用强制点击穿过未知弹窗。

## 封面

实际跑通的路径：

1. 悬停“拖拽或选择封面”。
2. 点击此时可见的“从图片库选择”。悬停菜单可能消失，尽量连续完成两步。
3. 在图片选择弹窗里上传用户指定的图片，核对选中的是本篇封面。
4. 点击“下一步”，等待封面裁剪窗口出现。
5. 检查消息列表横图和转发卡片方图裁剪，点击“确认”。

“下一步”并不意味着裁剪完成。未关闭裁剪窗口时，下层的发表按钮仍可被定位到，但不能点击。

## 创作来源声明

AI 生成文章需要如实声明。实际路径是编辑器的“创作来源”区域 → “未添加”/来源设置 → “内容由AI生成” → “确认”。本次来源入口为 `#js_claim_source_area .js_claim_source_desc`，使用前须核对当前页面。

如果先点击发表，微信可能提示“去声明”。点击后可能只滚动回设置区，不会自动打开来源选择弹窗。单击“创作来源”文字也不一定打开设置，实际应操作右侧可点击入口。

## 正式发表

1. 点击编辑器“发表”。
2. 在发表弹窗检查“群发通知”“分组通知”“定时发表”。此次实测群发通知默认开启。用户只要求发表时关闭通知，按用户要求设置定时状态。
3. 关闭某项开关可能让其他控件消失，重新读取当前状态，不使用先前缓存的下标继续点击。
4. 自定义开关的原生 checkbox 可能在可视区之外。点击其可见关联标签/开关，再读取 checked 状态；不直接修改 DOM 状态来伪造选择。
5. 在该弹窗内点击最终“发表”。未开启群发时，微信还可能弹出“未开启群发通知”，确认后点击“继续发表”。
6. 若出现扫码验证或管理员确认，交给用户完成。若要求声明、审核或返回错误，按真实提示处理。
7. 转到发表记录，按 [结果检查](result-check.md) 验证本篇文章。

不要自动开启群发来省略确认步骤，也不要因为一个请求超时就重复发表。
